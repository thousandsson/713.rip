# 713.rip

**当前版本 v1.1.0**（2026-10-11）· [改动记录](CHANGELOG.md) · [版本发布](https://github.com/thousandsson/713.rip/releases)

> 你的周末不属于学校

「713」是一周 **7** 天、平均每天 **13** 小时在校；「rip」是墓碑。

一个静态网页，做三件事：

1. **公示**占用休息日组织集体补课、强制返校自习的学校——附作息、证据与所违反的规定；
2. 列出全国通用的**规定原文**，全部附可点开的官方链接；
3. 给出能真正受理的**举报渠道**，附打电话时怎么说。

站点纯静态：一个 HTML、一个 CSS、一个 JS 数据文件。没有框架、没有依赖、没有构建步骤。

线上地址：<https://thousandsson.github.io/713.rip/>

---

## 文件

```
index.html     页面本体（结构 + 渲染逻辑）
style.css      样式
data.js        学校名单数据 + 站点版本号（日常只需要改这个）
CHANGELOG.md   改动记录
evidence/      证据图片放这里（自己新建这个文件夹）
.nojekyll      可选。告诉 GitHub Pages 不要用 Jekyll 处理
```

## 版本

页脚显示的版本号来自 `data.js` 里的 `SITE_VERSION`，只有这一个来源。改版本时三处一起动：

1. `data.js` 的 `SITE_VERSION`
2. `CHANGELOG.md` 加一条
3. GitHub 仓库 → `Releases` → `Draft a new release`，tag 用同名（如 `v1.1.0`），标题写一句话

版本规则：`v主.次.修订` —— 主＝页面结构或定位大改，次＝加内容/改版式/改交互，修订＝改错字、改链接、改数据。

## 加一所学校

编辑 `data.js`，照着里面的示例加一个对象：

```js
{
  name: "学校全名",
  region: "四川 · 南充 · 高坪区",
  brief: "一句话概况，折叠时显示",
  schedule: [
    ["周一～周五 在校", "7:30 — 22:00"],
    ["周六 在校", "7:30 — 17:20"]
  ],
  violations: [
    { name: "《学校卫生工作条例》第五条", link: "#law-health" },
    { name: "南充市《关于严格落实中小学生作息时间要求的通知》", link: "#law-nc-time" }
  ],
  images: [
    { src: "evidence/xxx-01.jpg", caption: "周六上午的教室" }
  ],
  evidence: "班级群通知截图、课程表",
  added: "2026-10-11"
}
```

**收录条件，三条缺一不可**：有全名、有具体事实、有可查证的材料。

页面上 `violations` 这一栏的标题是「**对照**」——只列规定名称，不做“违规”认定，供读者自行比对。`link` 指向页面上那条规定的锚点，可用的有：

| 锚点 | 对应 |
|---|---|
| `#law-health` | 《学校卫生工作条例》第五条 |
| `#law-minor` | 《未成年人保护法》第三十三条 |
| `#law-sleep` | 教育部 教基厅函〔2021〕11 号 |
| `#law-nc-time` | 南充市作息时间通知 |
| `#law-nc-ten` | 南充市减负十条 |
| `#law-gaozhong` | 国办发〔2019〕29 号 |

## 加证据图片

1. 在仓库里新建 `evidence/` 文件夹：`Add file` → `Create new file` → 文件名填 `evidence/keep.txt`，内容随便写一个字，提交。
2. 进去后 `Add file` → `Upload files`，把照片传进去。
3. 回到 `data.js`，在该校的 `images` 里写路径：

```js
images: [
  { src: "evidence/xxx-01.jpg", caption: "周六 15:00，教室在上课" }
]
```

**上传前先处理图片**：

- 打码人脸、姓名、群昵称、学号
- 手机照片动辄 3–5 MB，压到 500 KB 以内、宽度 1200px 左右就够
- 路径区分大小写：`evidence/`，不是 `Evidence/`

## 收集证据

收件邮箱在页面上（“四、把证据发过来”一节）。

原则：

- 只公示**有材料**的学校，材料不足的来信会先问清楚，不直接挂上去；
- **不公开**提交者身份，也不在页面上显示联系方式；
- 条目措辞采用“据来信者提供的材料”；任何学校或个人认为与事实不符，可以通过同一邮箱提出，核对后更正或撤下。
