# 713.rip

> 你的周末不属于学校

「713」是一周 **7** 天、平均每天 **13** 小时在校；「rip」是墓碑。

一个静态网页，收录三样东西：

1. **规定原文** —— 占用休息日补课、强制自习能用得上的法律与文件，全部附可点开的官方链接；
2. **举报渠道** —— 从 12345 到国务院“互联网＋督查”，附打电话时怎么说；
3. **学校名单** —— 只收录有证据支撑的条目。

站点纯静态：一个 HTML、一个 CSS、一个 JS 数据文件。没有框架、没有依赖、没有构建步骤。

---

## 文件

```
index.html     页面本体（结构 + 渲染逻辑）
style.css      样式
data.js        学校名单数据（日常只需要改这个文件）
.nojekyll      告诉 GitHub Pages 不要用 Jekyll 处理，保持原样发布
```

## 本地预览

直接双击 `index.html` 就能看。或者起一个本地服务器：

```bash
python3 -m http.server 8000
# 然后浏览器打开 http://localhost:8000
```

## 部署到 GitHub Pages

全程在浏览器里点，不需要命令行。

**1. 注册 GitHub 账号**

打开 https://github.com/signup ，用一个**专门注册的邮箱**（不要用日常邮箱，用户名也不要用真名）。

**2. 新建仓库**

右上角 `+` → `New repository`。

- Repository name：`school-icu`（或你喜欢的名字，会出现在网址里）
- 选 **Public**（Pages 免费版需要公开仓库）
- 不要勾选 Add a README file
- 点 `Create repository`

**3. 上传文件**

在新仓库页面点 `uploading an existing file`，把 `index.html`、`style.css`、`data.js`、`.nojekyll` 一起拖进去。

> `.nojekyll` 是隐藏文件，拖拽时如果看不见，在文件管理器里打开“显示隐藏文件”再选。

提交信息随便写，点 `Commit changes`。

**4. 打开 Pages**

仓库 → `Settings` → 左侧 `Pages`。

- Source 选 **Deploy from a branch**
- Branch 选 **main**，目录选 **/ (root)**
- 点 `Save`

等 1～2 分钟，刷新页面，顶部会出现你的网址：

```
https://你的用户名.github.io/school-icu/
```

**5. 以后要改内容**

直接改 `data.js`：在仓库里点开它 → 铅笔图标编辑 → 提交。网站一分钟左右自动更新。

## 加一条学校

编辑 `data.js`，照着里面的注释示例加一个对象：

```js
{
  name: "学校全名",
  region: "四川 · 南充 · 高坪区",
  facts: ["具体日期、时段、安排"],
  basis: ["所依据的文件与条款"],
  evidence: "通知截图 / 课表 / 考勤记录",
  added: "2026-10-11"
}
```

**收录条件，三条缺一不可**：有全名、有具体事实、有可查证的证据。

数组为空时页面显示“暂时还没有条目”，不会有空表格。

---

## 收集证据

收件邮箱在页面上（“三、把证据发过来”一节）。

原则：

- 只公布**有材料**的学校，材料不足的来信会先问清楚，不直接挂上去；
- **不公开**提交者身份，也不在页面上显示联系方式；
- 任何学校或个人认为条目与事实不符，可以通过同一邮箱提出，核对后更正或撤下。
